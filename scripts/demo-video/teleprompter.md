# Three-minute narration

## 0:00-0:20

> Alice is the authenticated human. Every Agent she owns has a different
> non-human principal, so owning an Agent does not silently give it all of her
> access.

## 0:20-1:05

> Alice can discover that Bob has a protected document, but private metadata is
> redacted. Neither Alice nor her Agent owns it. The backend denies this before
> execution and still records the human, Agent principal, action, resource,
> reason, and receipt hash. No protected file entered a Runtime.

## 1:05-1:45

> Now Alice explicitly attaches her own travel profile to one team task. That
> consent creates separate read-only capabilities for the selected specialists,
> each bound to this task ID. The Lead coordinates but never receives the raw
> document.

## 1:45-2:25

> The Lead chooses who should work next. Before every specialist turn, policy
> checks the exact principal, document, action, expiry, revocation state, and
> task. Only then is the document mounted read-only into that disposable turn.

## 2:25-3:00

> The specialists use the protected dates, budget, and preferences, while the
> Lead synthesizes their labelled contributions. When the task ends, every task
> capability is revoked automatically.
>
> Delegation decided who worked; capability policy decided what each Agent could
> read. Neither authority was claimed by a model, and both are tamper-evident.
